# Design

[R-005](docs/collab/reviews/R-005.md) defines the G5 slice. The [plan](docs/collab/plans/PLAN.md) records the pipeline model and later gates. The report store uses versioned PostgreSQL migrations. The first migration owns reports, saved specs, drafts and runs. Later migrations add automatic trigger state, run leases and scoped observations, report titles and draft head guards, personal templates, schedule definitions, and persisted chat turns and events.

An analyst edits one declarative object per section. The compiler expands fiscal presets into ordered offsets and emits inspectable stages. A section can combine benchmark facts and document passages. The renderer retains exact decimal values, unit provenance, resolved fiscal periods and opaque citations. The themes gateway proposes sentences with source IDs. Candidates exclude obvious call logistics and greetings, and are ranked across blocks and speakers by financial terms, instruction focus and quantitative detail. Optional configured embeddings can contribute distance. Document retrieval uses weighted full-text ranking with a plain-language topic crosswalk. A deterministic validator admits each claim only when every cited passage supplies the full claim unit and its selected topic. If no proposal passes, the engine uses cited quotes. The minimal policy and topic matching are in [claims.py](src/aegis_report/claims.py) and [sources.py](src/aegis_report/sources.py).

The FastAPI server derives the owner from the verified subject and enforces it on documents, runs, outputs and citation lookups. A preview snapshots a draft revision and can compare it with a saved output for the same fiscal period. The diff includes row moves, before/after cells and claim changes, and lists each side's resolved periods. Saving creates a new immutable version inside one transaction. A historical draft keeps its selected version for content and comparison and separately pins the head observed when editing started. Rename updates the catalog title. Existing version specs and artifacts retain their titles. Personal templates snapshot an authorized saved spec.

Run claims use a short transaction and an expiring attempt token. Source retrieval and model calls run after the claim transaction. Finalization requires the matching unexpired attempt. Source probes and retrieval use the same read-only snapshot. Previews and manual runs render current available evidence and show each scope's readiness and stability. Internally submitted automatic runs wait for all required scopes to produce consecutive stable observations across the quiet interval. Optional gaps appear in the output. A staged section can stop after retrieval. Full section previews record calculation, claims, numeric checks and formatted blocks. Finished saved runs generate printable PDFs offline from report blocks, with numbered links to source footnotes. Expired work can be reclaimed up to three consecutive attempts. An explicitly enqueued schedule definition pins a version and a quarter. Discovery of due periods, publication and correction handling belong to G6.

RTS retrieval strips HTML comments and page markers, suppresses short weak chunks, weights section headings, summary titles and body text in that order, and takes at most two chunks from each document page. Matching management discussion and figure-bearing passages receive a boost. Absolute and relative floors limit weak matches. Document claims quote complete prose or bullet highlights. RTS can join an adjacent chunk of the same file and page into one cited sentence. Reference sections and definitions are excluded for general summaries. The evaluator can print both the shortlisted units and accepted claims. [PostgreSQL text ranking](https://www.postgresql.org/docs/15/textsearch-controls.html)

The section spec accepts a single bank, an explicit list or the Big 6 Canadian group. Group membership uses the six core symbols and their availability catalog tags. KPI rows retain their bank and period, and diffs use the same keys. Peer calculations require every selected bank, the vendor fiscal-label basis, the same known units and mapped currency, and a consistent change basis. Rank 1 follows the KPI metadata direction. Ties share rank, with symbols breaking display order. Unknown direction produces ordered values. Currency mappings are labeled unconfirmed. [Peer calculation](src/aegis_report/peers.py)

A conversation binds an owner, draft and fiscal period. Turns are persisted, idempotent by request key and limited to one active turn per conversation. A worker claims the turn with an expiring lease. Replayable SSE events have increasing turn-local IDs. The JSON result carries the same terminal state, proposal and preview reference. The assistant's tools return bounded untrusted data and can propose typed operations or enqueue a preview. The owner applies the proposal through a separate transaction guarded by the proposed draft revision. The same turn accepts once. Saving, sharing and schedule changes are outside the assistant's tool surface. [Chat tools](src/aegis_report/chat_agent.py), [event store](src/aegis_report/chat_store.py), [SSE wire format](https://html.spec.whatwg.org/multipage/server-sent-events.html)


G5 serves a thin developer console through the loopback fixture with allowlisted stub identities and no hosted asset dependencies. It shares the same API and worker as the CLI demo. The canonical reason catalog supplies preview scope messages and chat and frontend wording. The handoff defines API, SSE, accessibility, error recovery and operations. [Frontend and API handoff](docs/integration/functions-assist-ui.md), [reason catalog](src/aegis_report/reasons.py)
