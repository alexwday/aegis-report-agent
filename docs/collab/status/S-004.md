## Summary

G3 ranks substantive earnings sentences before drafting and ranks slides and RTS passages by topic phrases and headings. Two read-only commands let the reviewer judge both changes against live sources. The report API exposes intermediate section results, owner-scoped report and template management, and offline PDF export with linked footnotes. Citation detail and pinned schedule definitions are available. Local verification used synthetic sources and passed 49 tests.
