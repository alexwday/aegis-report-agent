# Design

[R-002](docs/collab/reviews/R-002.md) defines the G2 slice. The [plan](docs/collab/plans/PLAN.md) records the pipeline model and later gates. The report store uses versioned PostgreSQL migrations. The first migration owns reports, saved specs, drafts and runs. The second adds automatic trigger state, run leases and scoped source observations.

An analyst edits one declarative object per section. The compiler expands fiscal presets into ordered offsets and emits inspectable stages. A section can combine benchmark facts and document passages. The renderer retains exact decimal values, unit provenance, resolved fiscal periods and opaque citations. The themes gateway proposes sentences with source IDs. A deterministic validator admits each claim only when every cited passage supplies the full sentence and its selected topic. If no proposal passes, the engine uses cited quotes. The minimal policy and topic matching are in [claims.py](src/aegis_report/claims.py) and [sources.py](src/aegis_report/sources.py).

The FastAPI server derives the owner from the verified subject and enforces it on documents, runs, outputs and citation lookups. A preview snapshots a draft revision and can compare it with a saved output for the same fiscal period. The diff includes row moves, before/after cells and claim changes, and lists each side's resolved periods. Saving creates a new immutable version inside one transaction.

Run claims use a short transaction and an expiring attempt token. Source retrieval and model calls run after the claim transaction. Finalization requires the matching unexpired attempt. Source probes and retrieval use the same read-only snapshot. Previews and manual runs render current available evidence and show each scope's readiness and stability. Internally submitted automatic runs wait for all required scopes to produce consecutive stable observations across the quiet interval. Optional gaps appear in the output. Discovery of due periods, publication and correction handling belong to G6.
